# Q&A：为什么累积相位补偿（σ）与标准差分补偿（e_std）改动前后等价？（2026-07-26）

> 背景：FPGA SSC PLL + DTC 项目，MASH 1-1（stage_sel = 2'b10），M = 2^FRAC_WIDTH = 1024。
> 前一篇（2026-07-25）给出了把 fractionaln.v 中 E_combined 从 σ 改为 e_std 的方案，
> 本文档解释两种做法等价的数学原理。

---

## 问题

为什么把 E_combined 从累积相位补偿 σ 改成标准差分补偿 e_std = e1 − y2·M 之后是等价的？请详细解释。

---

## 回答

**一句话：等价不是巧合——"积分"这件事第一级 EFM 的累加器已经替你做过了，没必要再搭第二个积分器。** 分三层说明。

### 第一层：补偿的物理对象

理想小数分频每周期的分频比应为 N + x/M，但实际分频器只能按整数 N + y_o[n] 分频。
每过一个分频周期，输出边沿相对理想位置偏差 (y_o[n] − x/M)·Tvco，该偏差**逐拍累积**。
DTC 要抵消的正是这个累积相位误差：

```
Φ[n] = Σ ( y_o[k] − x/M )        （单位：Tvco）
```

信号流：x → 第一级 EFM（残差 e1 = acc1 mod M）→ 第二级 EFM（进位 y2 ∈ {0,1}）；
y1、y2 经 Combiner 得 y_o = y1 + y2 − y2_d ∈ {−1,0,1,2}，送多模分频器（分频比 N + y_o）。

代码里的 σ 就是在整数域（×M）复算这个累积和：

```verilog
// fractionaln.v 第 47 行（改动前）
assign sigma_w = sigma + $signed(Fraction_d3) - $signed(delta_sigma) * $signed(13'sd1024);
// 即 σ[n] = σ[n−1] + x − y_o[n]·M
```

### 第二层：裂项相消——为什么积分可以不用自己做

把 combiner 表达式 y_o = y1 + y2[k] − y2[k−1] 代入 σ 的求和，拆成两项，**两项各自"塌缩"**：

**项 A：Σ ( x − y1[k]·M ) = e1[n]**

第一级 EFM 的递推是 e1[n] = e1[n−1] + x − y1[n]·M——它的累加器本身就在计算这个和，
残差寄存器 e1 就是部分和，**是调制器里现成的量，不用另算**。

**项 B：Σ ( y2[k] − y2[k−1] ) = y2[n]**

差分形式，裂项相消（telescoping）：

```
B = (y2[0]−y2[−1]) + (y2[1]−y2[0]) + (y2[2]−y2[1]) + ⋯ + (y2[n]−y2[n−1])
    中间项两两抵消  ⇒  B = y2[n] − y2[−1] = y2[n]（初值 y2[−1] = 0）
```

合并（注意符号：σ = Σ(x − y_o·M) = A − M·B）：

```
σ[n] = e1[n] − y2[n]·M + C = e_std[n] + C
```

### 第三层：严格证明与常数 C 的处理

定义 D[n] = σ[n] − e1[n] + y2[n]·M，则：

```
D[n] − D[n−1] = (x − y_o[n]·M) − (x − y1[n]·M) + (y2[n] − y2[n−1])·M
              = −M·( y_o[n] − y1[n] − y2[n] + y2[n−1] )
              = −M·( y_o[n] − y_o[n] ) = 0
```

D 为常数；零初始化（σ=0, e1=0, y2[−1]=0）时 D = 0，故 σ[n] 与 e_std[n] **逐拍严格相等**，
不是近似等价。即使 C ≠ 0，它在相域只是固定相位偏移——PLL 锁定时 PFD 两输入本来就允许
静态相位差（靠电荷泵电流微小失衡维持），环路会把它吸收进锁定点，对抖动和噪声传递无影响。

### 为什么观测范围不同（±2Tvco vs ±Tvco）

两种做法数学上是同一个量，理论界相同；差别在于**界是怎么维持的**：

| | σ（积分器） | e_std（前馈） |
|---|---|---|
| 界的来源 | 涌现的：靠 x 与 y_o 每拍精确对拍维持 | 构造性的：e1 取模天然落在 [0, M) |
| 失配后果 | 误差被永久积分，随机游走，实测摆幅约 ±2Tvco | 错一拍只错一拍，下一拍自动回界 |
| 寄存器限幅 | 无任何限幅机制 | y2·M 项把残差中心化到 (−M, +M) |
| DTC 量程需求 | 双倍（码值浪费一半） | 减半，INL 影响同步减半 |

y2·M 项的直觉：第二级每打一次进位，分频比就多计一个 VCO 周期，要补的相位就要减 M；
正是这一项把 [0, M) 的残差拉成 (−M, +M) 的居中形式（±Tvco）。

---

## 结论

改成标准做法**不改变任何补偿效果**（数学上是同一个物理量的两种实现）：

- σ = 自己再搭一个积分器复算相位；
- e_std = 直接读出调制器内部已经积好的残差，再加一拍 y2 修正。

换来的是：DTC 量程需求减半、DTC 非线性（INL）影响减半、对流水线时序失配免疫——
这就是论文中普遍采用前馈形式的原因。
