Q&A：为什么累积相位补偿（σ）与标准差分补偿（e_std）改动前后等价？

2026-07-26 ｜ FPGA SSC PLL + DTC 项目 ｜ MASH 1-1（stage_sel = 2'b10），M = 1024
问题 为什么改动前后是等价的呢，可否详细解释一下？

回答

等价不是巧合——核心原因是："积分"这件事，第一级 EFM 的累加器已经替你做过了，没必要再搭第二个积分器。分三层讲清楚。

第一层：补偿的物理对象是什么。理想小数分频每周期的分频比应该是 N + x/M，但实际分频器只能按整数 N + y_o[n] 分频。每过一个分频周期，输出边沿就相对理想位置偏差 (y_o[n] − x/M)·Tvco，这个偏差是逐拍累积的。DTC 要抵消的正是这个累积相位误差 Φ[n]：

第二层：裂项相消——为什么积分可以不用自己做。代码里的 sigma 就是在复算这个累积和（乘上 M=1024 变成整数域）：σ[n] = Σ(x − y_o[k]·M)。把 combiner 的表达式 y_o = y1 + y2[k] − y2[k−1] 代进去，求和会拆成两部分，而两部分都各自"塌缩"了：

第三层：严格证明与常数 C 的处理。上面的裂项相消可以写成一行严格的递推证明。定义 D[n] = σ[n] − e1[n] + y2[n]·M，则：

D[n] − D[n−1] = (x − y_o[n]·M) − (x − y1[n]·M) + (y2[n] − y2[n−1])·M
              = −M·(y_o[n] − y1[n] − y2[n] + y2[n−1])
              = −M·(y_o[n] − y_o[n]) = 0

D 是常数，且零初始化时 D = 0，所以 σ[n] 和 e_std[n] 逐拍严格相等，不只是"近似等价"。即使初值不为零，常数 C 在相域只是一个固定相位偏移——PLL 锁定时 PFD 两输入本来就允许一个静态相位差（靠电荷泵电流的微小失衡维持），环路会把它当作锁定点的一部分吸收掉，对抖动和噪声传递毫无影响。

那为什么说范围不同（±2Tvco vs ±Tvco）？关键在于这个"界"是怎么来的：σ 的界是涌现的——数学上它确实等于 e_std，但它的寄存器本身没有任何限幅机制，这个等式要靠 x 与 y_o 每拍精确对拍来维持。一旦流水线失配、或 SSC 扫描期间 x 在变化，混入的误差会被积分器永久累积，实测摆幅就到了 ±2Tvco。而 e_std 的界是构造性的：e1 是取模残差，天然落在 [0, M)，减去 y2·M（第二级每打一次进位，分频比就多计一个 VCO 周期，正好把残差中心化）后严格落在 (−M, +M)，错一拍也只错一拍，下一拍自动回界内：

总结

  1. 补偿对象：分频器输出的累积相位误差 Φ[n] = Σ(y_o[k] − x/M)·Tvco，两种做法都是在整数域（×1024）复算它。
  2. 等价根源：把 y_o = y1 + y2 − y2_d 代入求和后，第一项的积分恰好就是第一级 EFM 的残差 e1（调制器内部现成的累加器），第二项是差分形式、裂项相消只剩 y2[n]。严格证明 D[n] = σ − e1 + y2·M 为常数，零初始化时两者逐拍完全相等；常数只表现为静态相位差，被 PLL 环路吸收。
  3. 工程差异：σ 是另搭的积分器，它的界靠完美对拍维持，失配误差被永久积分，实测摆到 ±2Tvco；e_std 是前馈直算，e1 取模天然有界，y2·M 项把残差中心化到严格 ±Tvco，对时序失配鲁棒。

所以改成标准做法不改变任何补偿效果（数学上就是同一个量），换来的是 DTC 量程需求减半、INL 影响减半、以及对流水线失配免疫——这就是论文里都用前馈形式的原因。

一句话概括：σ 是自己再搭一个积分器去复算相位，e_std 是直接读出调制器内部已经积好的残差再加一拍 y2 修正——两者是同一个物理量的两种实现，所以补偿效果相同；差别只在于前馈形式把范围严格限在 ±Tvco，这就是要改过去的原因。
