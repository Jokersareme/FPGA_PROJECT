# Q&A：MASH 1-1 下 E_combined 改为标准差分补偿（2026-07-25）

> 整理自 2026-07-25 会话。背景：FPGA SSC PLL + DTC 小数分频补偿项目，
> MASH 1-1（stage_sel = 2'b10），FRAC_WIDTH = 10（M = 1024），Tvco = 1.6ns，
> DTC 延迟 4ps/tap × 4 级 = 16ps/code，理想 dtc_gain = 100，offset = 256 居中。

---

## 问题

结合论文里的标准做法，把当前 fractionaln.v 中 E_combined 的**累积相位补偿**
（sigma 累加器）改成**标准差分补偿**（用第一级 EFM 残差直接前馈计算），
并说明两种做法的区别与等价性。

---

## 回答

### 1. 两种做法的区别

**当前做法（累积相位补偿）**，fractionaln.v 第 47 行：

```verilog
assign sigma_w = sigma + $signed(Fraction_d3) - $signed(delta_sigma) * $signed(13'sd1024);
```

sigma[n] = sigma[n-1] + x - y_o·M，即对量化误差做累加（积分）。
MASH 1-1 下 y_o = y_o_1 + y_o_2 - y2_d ∈ {-1, 0, 1, 2}，
累加器实际摆幅约 **±2Tvco**。

**标准差分补偿（论文做法）**：

```
e_std[n] = acc1[n] - y_o_2[n]·M
```

其中 acc1 是第一级 EFM 的残差（即 e_o_1，范围 [0, M)，代表 φ[n]×1024），
y_o_2 是第二级 EFM 的进位（0 或 1）。
e_std ∈ (-M, M)，范围严格 **±Tvco**，是有界的（由构造保证，不会漂移）。

### 2. 等价性推导

令 D[n] = sigma[n] - e_o_1[n] + y_o_2[n]·M，递推可得：

```
sigma[n] - e_o_1[n] = [sigma[n-1] - e_o_1[n-1]] - (y_o_2[n] - y_o_2[n-1])·M
=> D[n] = D[n-1] = 常数
=> sigma[n] = e_std[n] + const
```

结论：两种做法**数学上严格等价，只差一个常数**。该常数表现为静态相位差，
会被 PLL 环路（PFD/CP）自动吸收，因此理论上抖动性能相同。

### 3. 为什么要改

| 对比项 | 累积 sigma | 标准 e_std |
|---|---|---|
| 范围 | 约 ±2Tvco | 严格 ±Tvco |
| DTC 动态范围需求 | 双倍，浪费一半码值 | 减半 |
| 有界性 | 依赖 x 与 y_o 的精确对拍，失配会被积分放大、随机游走 | 构造上有界，对时序失配鲁棒 |
| DTC 非线性影响 | 摆幅大，INL 引入的误差更大 | 摆幅减半，误差减半 |

### 4. 具体修改方案

**(1) mash111.v：导出与 e_o 同拍的 y_o_2**

e_o 输出的是 eo_d1（e_o_1 打 1 拍），y_o_2 也要打同样 1 拍才能对齐：

```verilog
// 端口增加：
output reg y2_o,

// 与 eo_d1 同一个 always 块（posedge clk）：
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        eo_d1 <= 1'b0;
        y2_o  <= 1'b0;
        y_o   <= 4'b0;
    end else begin
        eo_d1 <= e_o_1;
        y2_o  <= y_o_2;          // 新增：与 eo_d1 同拍
        y_o   <= (stage_sel == 2'b00) ? c2 :
                 (stage_sel == 2'b01) ? y_o_1 :
                 $signed(y_o_1) + $signed(y_o_2) - $signed(y2_d);
    end
end
```

**(2) fractionaln.v：用 e_std 替换 sigma**

```verilog
// u_mash111 例化增加：
//     .y2_o (y2_std),
wire y2_std;

// 删除 sigma_w / sigma 累加器，改为前馈直算：
wire signed [FRAC_WIDTH+1:0] e_std;
assign e_std = $signed({2'b00, Eo_raw})
             - (y2_std ? $signed(13'sd1024) : $signed(13'sd0));

// negedge Fout 的 always 块中，sigma <= sigma_w 删除，改为：
Ec_d1 <= e_std;
Ec_d2 <= Ec_d1;
Ec_d3 <= Ec_d2;
E_combined <= (eo_dly_sel == 2'b00) ? e_std  :
              (eo_dly_sel == 2'b01) ? Ec_d1  :
              (eo_dly_sel == 2'b10) ? Ec_d2  : Ec_d3;
```

要点：
- Eo_raw 已经是 Fout 域打拍后的 e_o_1，y2_std 与其同拍，天然对齐；
- e_std 为 12bit 有符号数（-1024 ~ +1023），位宽与 E_combined 相同，下游接口不变；
- Fraction_d2/Fraction_d3、sigma、sigma_w 及相关复位分支可一并删除。

**(3) 下游 DTC 增益映射不变**

dtc_gain = 100（Tvco 1.6ns / 16ps per code），offset = 256 居中。
e_std 是有符号数，映射到 DTC code 时按有符号处理：
code = offset + e_std × gain / 1024 ≈ 256 ± 100，
码值占用从原来的约 ±200 缩减到 ±100，DTC 有效范围减半。
